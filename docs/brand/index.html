Usage rules

Small choices compound. Follow these to keep the mark consistent.

Do

  • Use the horizontal combination of icon and wordmark
  • Maintain clear contrast against the background
  • Keep generous clear space around the mark
  • Use SVG files for any size above 32px

Don't

  • Use the text-only wordmark without the icon
  • Stack vertically, rotate, or stretch the logo
  • Add gradients, strokes, or shadows
  • Place the logo on backgrounds with insufficient contrast
